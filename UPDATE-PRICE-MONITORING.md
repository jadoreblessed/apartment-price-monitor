# Обновление мониторинга цен

В корневой папке проекта, где находится `package.json`, выполните:

```powershell
npm install
npm run db:push
npm run competitor:add-new
npm run build
npm run start
```

Команда `db:push` добавляет поля даты, количества ночей и общей стоимости.
Команда `competitor:add-new` один раз добавляет согласованного конкурента к
первой квартире; повторный запуск не создаёт дубликат.

Дата проверки меняется менеджером в «Настройки квартиры». Для теста по
умолчанию установлено 15 сентября 2026 года. Если минимальный срок составляет
2–3 ночи, укажите это число: монитор сохранит общую стоимость и рассчитает цену
за одну ночь.

Расписание автоматической проверки: ежедневно в 08:00, 14:00 и 20:00. Для
установки или обновления задачи Windows выполните PowerShell от имени
администратора:

```powershell
npm run schedule:install
```
