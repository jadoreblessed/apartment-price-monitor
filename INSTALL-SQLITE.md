# Установка локальной версии SQLite

Эта версия не использует Neon или Vercel. База хранится локально в файле
`prisma/dev.db`.

## Безопасное обновление с сохранением данных

1. Остановите `npm run start` сочетанием `Ctrl+C`.
2. Переименуйте текущую папку проекта в `apartment-price-monitor-backup`.
3. Распакуйте архив как новую папку `apartment-price-monitor`.
4. Если в старой папке есть `prisma/dev.db`, скопируйте его в
   `apartment-price-monitor/prisma/dev.db`.
5. В новой папке создайте `.env` на основе `.env.example`.

Содержимое `.env`:

```env
DATABASE_URL="file:./dev.db"
AUTH_SECURE_COOKIE="0"
PROXY_SERVER="http://mobpool.proxy.market:10000"
PROXY_USERNAME="ваш_логин"
PROXY_PASSWORD="ваш_пароль"
```

Затем выполните:

```powershell
cd C:\Users\user\apartment-price-monitor
npm install
npm run db:push
npm run competitor:add-new
npm run build
npm run start
```

Основной режим теперь ручной: менеджер открывает Avito кнопкой на сайте,
переносит общую стоимость, а приложение считает цену за сутки и сохраняет
историю.

Автоматический скрейпер оставлен как экспериментальный режим. Для него отдельно
нужны:

```powershell
npx playwright install chromium
npm run avito:session
```

Команды загружают прокси из `.env`. Один IP используется на протяжении всего
прохода; новый браузерный контекст создаётся при следующем запуске. При ротации
раз в 30 минут желательно, чтобы один проход завершался быстрее 30 минут.

Мониторинг в экспериментальном режиме проверяет объявления последовательно с
паузой 10–25 секунд. При капче или ограничении доступа весь текущий проход
останавливается, чтобы не усиливать блокировку.

Если база была пустой, сначала откройте сайт, зарегистрируйтесь и добавьте свою
квартиру. После этого остановите сервер и выполните `npm run competitor:add-new`.

Расписание ручной проверки отображается в интерфейсе: `08:00`, `14:00` и
`20:00`. Старую задачу автоматического мониторинга можно не использовать.

Для ежедневной резервной копии базы выполните:

```powershell
npm run backup:schedule
```

Копии будут сохраняться в папку `backups` в 23:30.
